FPT Life — AI Feature Toggle Events

Mapping event tracking ↔ API path ↔ định nghĩa nghiệp vụ. Tài liệu chia sẻ cho đội Data.
App: FPT Life Android SDK: UniTrack 0.3.49 · FSDKTracking Vendor Snowplow: vn.fpt.ftel.snowplow Event name: camera_ai_feature_toggled Ngày cập nhật: 2026-08-04

1. Tổng quan

FPT Life theo dõi việc user bật/tắt các tính năng AI trên camera qua 1 event thống nhất: camera_ai_feature_toggled. Tất cả toggle (đèn LED, xoay hình, chế độ đêm, phát hiện chuyển động…) đều fire event này với ai_feature_code khác nhau để phân biệt.

Nơi track ViewModel / Composable của từng màn hình setting camera SDK API FSDKTracking.aiFeatureToggled(cameraSerial, aiFeatureCode, action, previousState, toggleSource) Iglu schema iglu:vn.fpt.ftel.snowplow/camera_ai_feature_toggled/jsonschema/1-0-0 Trigger point SAU khi API cập nhật cài đặt trả về thành công (trong completionHandler / block sau khi executeSuspend) Không track khi API fail (đi vào errorHandler) — nên số event = số lần đổi thành công

Convention đặt tên ai_feature_code: bám theo segment setting/ của API path, viết snake_case ngắn gọn. Ví dụ camera/setting/led-indicator/update/ → led_indicator. Không prefix vendor. Riêng rotate_image đặt semantic (thay vì rotate) để đọc tự nhiên. alert_method_mpn có suffix _mpn để không trùng với smart_alarm_*.

3. Payload gửi lên

3.1 Event structure

{
  "schema": "iglu:vn.fpt.ftel.snowplow/camera_ai_feature_toggled/jsonschema/1-0-0",
  "data": {
    "camera_serial":  "CAM-XYZ-12345",       // Serial thiết bị
    "ai_feature_code": "human_detect",       // 1 trong 8 code trong bảng trên
    "action":          "enable",             // Trạng thái mới sau toggle
    "previous_state":  "disabled",           // Trạng thái trước khi toggle
    "toggle_source":   "app_settings"        // Nguồn thao tác — hiện chỉ có "app_settings"
  }
}

3.2 Ví dụ event thực tế (bật human_detect)

FSDKTracking.aiFeatureToggled(
    cameraSerial  = "CAM-FLI-A1B2C3",
    aiFeatureCode = "human_detect",
    action        = "enable",
    previousState = "disabled",
    toggleSource  = "app_settings"
)

4. Lưu ý cho đội Data khi phân tích

⚠ Value của action hiện chưa đồng nhất — do implement từng feature bởi các dev khác nhau, hiện tại có 3 style trong DB:
ai_feature_code Value action đang gửi Ghi chú
led_indicator enable / disable Đúng chuẩn khuyến nghị (Snowplow doc)
motion_detect, human_detect enable / disable
rotate_image on / off Cần thống nhất về enable/disable (chưa sửa)
alert_method_mpn on / off
smart_alarm_light, smart_alarm_sound on / off
night_vision ir / full_color / auto (raw mode) Đây là enum 3+ giá trị, không phải toggle boolean. Xử lý riêng khi query.
Khi query DB, đội Data cần normalize action về boolean: 
CASE
  WHEN action IN ('enable', 'on', 'ir', 'full_color', 'auto') THEN 'enabled'
  WHEN action IN ('disable', 'off') THEN 'disabled'
  ELSE action
END AS state
Sau khi SDK đồng bộ về enable/disable cho toàn bộ code (sắp làm) thì có thể bỏ CASE này.

5. Trường hợp đặc biệt

SmartAlert — 2 event share 1 API

Cả smart_alarm_light và smart_alarm_sound đều gọi cùng API camera/setting/alarm/update/. Mỗi lần user toggle 1 trong 2 → gọi API 1 lần → fire 1 event tương ứng. Không double-count: nếu user bật light xong bật sound → có 2 event riêng biệt, 2 lần gọi API.

AutoAlert — cascade human ↔ motion

Trong AutoAlertViewModel, việc bật human_detect sẽ tự động bật kèm motion_detect nếu chưa bật. Ngược lại, tắt motion_detect sẽ tự tắt human_detect. Tuy nhiên chỉ event được user click trực tiếp mới fire tracking — event bị cascade KHÔNG track. Nếu cần phân tích cascade, join với timestamp gần nhau (<1s).

NightVision không phải toggle nhị phân

night_vision là enum mode, không phải on/off. Query cần group theo giá trị cụ thể của action để tính distribution: bao nhiêu % user chọn IR, bao nhiêu % chọn full color, bao nhiêu chọn auto.

6. Không track (chưa gắn event)

  • Alarm duration (thời lượng còi báo động) — mới chỉ track light/sound on-off, chưa track thay đổi số giây.
  • Offline detect — có API camera/setting/offline-detect/update/ nhưng chưa gọi aiFeatureToggled.
  • Watermark, Wifi change, Reboot — không thuộc phạm vi AI feature, không track qua event này.
