Ghi chú áp dụng cho mọi event

Những thay đổi horizontal — không lặp lại trong từng diff bullet

  • event_action stamp: SDK auto-stamp event_action = raw event name vào payload chính. Data team pivot trực tiếp không cần crack schema.
  • session_id auto-stamp: Mọi event đều có session_id ở payload chính + trong core_action context.
  • Context core_action: nay có đủ action_name, timestamp, start_time, session_id (thay vì chỉ start_time).
  • Context application_context: nay có ~26 field device/network/app info (spec cũ chỉ 5 field). SDK tự collect, app không cần truyền.
  • Type conversion: Tất cả số → String để parity Iglu schema. Ví dụ: "session_index": "12" thay vì 12. Snowplow enricher expect string form.
  • PII hashing: user_id, user_name, phone_number đều SHA-256 hash trước khi bắn.
  • Lifecycle events drop: 2 event app_foreground/app_background đã chặn tại provider (đội data không cần define schema).
  • screen_viewed: fire cả khi app resume từ background (không chỉ lúc navigate).
  • screen_exited: tách schema riêng iglu:.../screen_end/1-0-0 (không share với screen_view). Có 2 trigger: (1) navigate away, (2) app đi background — phân biệt qua field reason.
  • Per-screen counters: foreground_sec/background_sec reset mỗi lần setScreen mới, match Snowplow builtin screen_summary/1-0-0 semantic.
