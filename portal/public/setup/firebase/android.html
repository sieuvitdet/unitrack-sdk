Tích hợp Firebase vào dự án Android Native

Hướng dẫn này áp dụng cho cả Groovy DSL (.gradle) và Kotlin DSL (.gradle.kts) — chỉ tốn ~7 phút.

⚙ Yêu cầu trước khi bắt đầu Android Studio Hedgehog+ · Gradle 8+ · Google account để dùng Firebase Console.

1 Tạo Firebase project

Vào Firebase Console → "Thêm dự án" → đặt tên (vd my-app-android) → bật/tắt Google Analytics tuỳ nhu cầu.

2 Đăng ký app Android trong Firebase project

Click "Add app" → biểu tượng Android. Điền:

  • Android package name: lấy từ app/build.gradle → applicationId (vd asia.mobix.myapp)
  • App nickname: tuỳ ý
  • SHA-1 (tuỳ chọn): cần nếu dùng Google Sign-In / Dynamic Links. Lấy từ:
    Terminal
    ./gradlew signingReport

3 Download google-services.json

Firebase Console sẽ hiện nút "Download google-services.json" — tải về và đặt vào thư mục app/ (cùng cấp với app/build.gradle).

⚠ Multi-flavor (dev / staging / prod)? Tạo Firebase app riêng cho mỗi applicationId + suffix. Đặt file google-services.json vào folder flavor tương ứng: app/src/dev/google-services.json, app/src/prod/google-services.json. Gradle sẽ tự pick đúng file theo build variant.

4 Khai báo Google Services plugin

Mở build.gradle ở thư mục root (project-level):

Groovy · build.gradle (project)
// Trong block 'plugins' ở đầu file
plugins {
    // ... existing plugins
    id 'com.google.gms.google-services' version '4.4.2' apply false
    id 'com.google.firebase.crashlytics' version '3.0.2' apply false
}

Hoặc cho Kotlin DSL:

Kotlin · build.gradle.kts (project)
plugins {
    // ... existing plugins
    id("com.google.gms.google-services") version "4.4.2" apply false
    id("com.google.firebase.crashlytics") version "3.0.2" apply false
}

5 Apply plugin và thêm dependencies trong app/build.gradle

Groovy · app/build.gradle
plugins {
    id 'com.android.application'
    id 'org.jetbrains.kotlin.android'
    id 'com.google.gms.google-services'         // ← Thêm
    id 'com.google.firebase.crashlytics'        // ← Thêm
}

dependencies {
    // Firebase BoM — quản lý version đồng bộ
    implementation platform('com.google.firebase:firebase-bom:33.5.1')

    implementation 'com.google.firebase:firebase-analytics'
    implementation 'com.google.firebase:firebase-crashlytics'

    // ... existing dependencies
}

Hoặc Kotlin DSL:

Kotlin · app/build.gradle.kts
plugins {
    id("com.android.application")
    kotlin("android")
    id("com.google.gms.google-services")
    id("com.google.firebase.crashlytics")
}

dependencies {
    implementation(platform("com.google.firebase:firebase-bom:33.5.1"))

    implementation("com.google.firebase:firebase-analytics")
    implementation("com.google.firebase:firebase-crashlytics")
}

6 Khởi tạo Firebase trong Application

Tạo class MyApplication (nếu chưa có) hoặc sửa class hiện có:

Kotlin · MyApplication.kt
package asia.mobix.myapp

import android.app.Application
import com.google.firebase.FirebaseApp
import com.google.firebase.crashlytics.FirebaseCrashlytics

class MyApplication : Application() {
    override fun onCreate() {
        super.onCreate()
        FirebaseApp.initializeApp(this)
        FirebaseCrashlytics.getInstance().isCrashlyticsCollectionEnabled = true
    }
}

Khai báo trong AndroidManifest.xml:

XML · AndroidManifest.xml
<application
    android:name=".MyApplication"
    ...>
    <!-- ... -->
</application>

7 Sync Gradle và build

Android Studio sẽ tự nhận diện google-services plugin. Click "Sync Now" → build app.

Nếu sync thất bại với "File google-services.json is missing", kiểm tra:

  • File ở đúng app/google-services.json chứ KHÔNG phải root google-services.json
  • Multi-flavor: file trong app/src/{flavor}/google-services.json

8 Bật forward UniTrack → Firebase

Mở Portal → Project → tab Config (remote) → bật toggle "Firebase Analytics / Crashlytics" → Lưu. SDK UniTrack sẽ tự nhận config qua SSE.

✓ Checklist hoàn thành

  • Tạo Firebase project
  • Đăng ký Android app với đúng applicationId
  • Đặt google-services.json vào app/
  • Thêm 2 plugin google-services + firebase-crashlytics
  • Thêm Firebase BoM + analytics + crashlytics dependencies
  • Gọi FirebaseApp.initializeApp(this) trong Application
  • Sync Gradle, build, chạy app — Firebase Console nhận data sau ~5 phút
  • Bật toggle Firebase trên Portal

🆘 Gặp lỗi?

  • "File google-services.json is missing": đặt sai chỗ. Phải nằm trong app/, không phải root.
  • "No matching client found for package name": applicationId trong gradle ≠ package name lúc đăng ký Firebase. Kiểm tra cả 2.
  • Build chậm: là bình thường lần đầu cài plugin, sync xong lần 2 sẽ nhanh.
  • Crashlytics không nhận crash: đảm bảo build với buildType debug = false (Crashlytics mặc định disable trong debug), hoặc force enable bằng isCrashlyticsCollectionEnabled = true.
