📘 Setup Firebase ⚛ React Native

🍎 iOS Native 🤖 Android Native 🐦 Flutter ⚛ React Native

Tích hợp Firebase vào dự án React Native

Dùng @react-native-firebase/*. Hỗ trợ cả bare RN CLI và Expo (managed/EAS). Tốn ~10 phút cho cả 2 platform.

⚙ Yêu cầu trước khi bắt đầu Node ≥ 18 · React Native ≥ 0.72 · CocoaPods (iOS) · Android SDK Tools. Nếu dùng Expo, cần dùng custom dev client (không chạy được trên Expo Go vì native module).

1 Tạo Firebase project + đăng ký 2 app

Vào Firebase Console → tạo project →

  • Đăng ký iOS app với bundle ID (lấy từ ios/YourApp.xcodeproj)
  • Đăng ký Android app với package name (lấy từ android/app/build.gradle → applicationId)
  • Tải GoogleService-Info.plist → đặt vào ios/YourApp/
  • Tải google-services.json → đặt vào android/app/

2 Cài @react-native-firebase/* packages

Terminal · npm
npm install @react-native-firebase/app
npm install @react-native-firebase/analytics
npm install @react-native-firebase/crashlytics

Hoặc yarn:

Terminal · yarn
yarn add @react-native-firebase/app
yarn add @react-native-firebase/analytics
yarn add @react-native-firebase/crashlytics

3 Sửa Android Gradle

Mở android/build.gradle (project-level), thêm classpath:

Groovy · android/build.gradle
buildscript {
    dependencies {
        // ... existing
        classpath 'com.google.gms:google-services:4.4.2'
        classpath 'com.google.firebase:firebase-crashlytics-gradle:3.0.2'
    }
}

Mở android/app/build.gradle, thêm dưới cùng file:

Groovy · android/app/build.gradle
apply plugin: 'com.google.gms.google-services'
apply plugin: 'com.google.firebase.crashlytics'

4 Setup iOS

Mở ios/YourApp/AppDelegate.mm (hoặc .m):

Objective-C · AppDelegate.mm
#import <Firebase.h>    // ← Thêm

@implementation AppDelegate

- (BOOL)application:(UIApplication *)application
    didFinishLaunchingWithOptions:(NSDictionary *)launchOptions {
    [FIRApp configure];    // ← Thêm DÒNG NÀY TRƯỚC return YES;

    // ... existing code
    return YES;
}
@end

Chạy pod install:

Terminal
cd ios
pod install --repo-update
cd ..

5 Verify trong JS code

Tạo file src/firebase.ts:

TypeScript · src/firebase.ts
import firebase from '@react-native-firebase/app';
import analytics from '@react-native-firebase/analytics';
import crashlytics from '@react-native-firebase/crashlytics';

// Firebase tự init từ GoogleService-Info.plist và google-services.json
// — không cần gọi initializeApp() thủ công trong RN.

export async function logAppOpen() {
  await analytics().logAppOpen();
}

export function enableCrashlytics() {
  crashlytics().setCrashlyticsCollectionEnabled(true);
}

6 Build & chạy

Terminal
# iOS
npx react-native run-ios

# Android
npx react-native run-android

7 Setup Expo (nếu dùng Expo)

Expo Go không hỗ trợ @react-native-firebase. Phải dùng custom dev client:

Terminal · Expo
# Cài expo-build-properties + dev client
npx expo install expo-build-properties expo-dev-client

# Cấu hình app.json
# Thêm plugin section
JSON · app.json
{
  "expo": {
    "plugins": [
      "@react-native-firebase/app",
      "@react-native-firebase/crashlytics",
      [
        "expo-build-properties",
        {
          "ios": { "useFrameworks": "static" }
        }
      ]
    ],
    "ios": {
      "googleServicesFile": "./GoogleService-Info.plist"
    },
    "android": {
      "googleServicesFile": "./google-services.json"
    }
  }
}

Build dev client:

Terminal
eas build --profile development --platform all

8 Bật forward UniTrack → Firebase

Mở Portal → Project → tab Config (remote) → bật toggle "Firebase Analytics / Crashlytics" → Lưu.

✓ Checklist hoàn thành

  • Tạo Firebase project + đăng ký iOS app + Android app
  • Đặt GoogleService-Info.plist vào ios/YourApp/
  • Đặt google-services.json vào android/app/
  • Cài @react-native-firebase/app + analytics + crashlytics
  • Sửa android/build.gradle + android/app/build.gradle
  • Gọi [FIRApp configure] trong AppDelegate (iOS)
  • Chạy pod install + run-ios + run-android
  • Firebase Console nhận data sau ~5 phút
  • Bật toggle Firebase trên Portal

🆘 Gặp lỗi?

  • "Default FirebaseApp is not initialized" trên iOS: thiếu [FIRApp configure] trong AppDelegate.
  • "Could not find google-services.json" Android: đặt vào sai chỗ. Phải nằm trong android/app/.
  • Pod install fail: xoá ios/Pods + ios/Podfile.lock → chạy lại pod install --repo-update.
  • Expo Go báo "Native module not found": phải dùng dev client, không phải Expo Go.
  • Crashlytics không nhận crash debug: đặt setCrashlyticsCollectionEnabled(true) rõ ràng (default disable trong debug build).
