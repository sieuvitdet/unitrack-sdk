Tích hợp Firebase vào dự án iOS Native

Hướng dẫn này giúp bạn cài Firebase Analytics + Crashlytics vào app iOS Native (Swift / Objective-C), chỉ tốn ~5 phút. Sau khi xong, bật toggle Firebase trên Portal và UniTrack sẽ tự forward mọi event sang Firebase.

⚙ Yêu cầu trước khi bắt đầu Đã có Apple Developer account · Xcode ≥ 15 · CocoaPods hoặc Swift Package Manager đã setup.

1 Tạo Firebase project

Vào Firebase Console → click "Thêm dự án" → đặt tên (vd my-app-ios) → tắt Google Analytics nếu chỉ cần Crashlytics, bật nếu cần cả 2.

Hình 1 · Firebase Console — chọn biểu tượng iOS để thêm app mới
(Nguồn: simoahava.com)

2 Đăng ký app iOS trong Firebase project

Trong Firebase project vừa tạo, click "Add app" → biểu tượng iOS. Điền:

  • Apple bundle ID: ví dụ asia.mobix.myapp (lấy từ Xcode → Target → General → Bundle Identifier)
  • App nickname: ghi gì cũng được, để dễ phân biệt
  • App Store ID: bỏ trống nếu chưa có
Hình 2 · Điền Bundle ID + nickname để Firebase đăng ký app
💡 Multi-flavor (dev / staging / prod)? Tạo 1 Firebase app cho mỗi bundle ID. Vd asia.mobix.myapp.dev, asia.mobix.myapp.staging, asia.mobix.myapp.

3 Download file GoogleService-Info.plist

Sau khi đăng ký app, Firebase Console hiện nút "Download GoogleService-Info.plist". Tải file này về máy — đây là file cấu hình quan trọng nhất.

Trong Xcode:

  • Mở project trong Xcode
  • Kéo file GoogleService-Info.plist vào thư mục root của target (cùng cấp với Info.plist)
  • Khi popup hiện, tick "Copy items if needed" và chọn target tương ứng
Hình 3 · Dialog "Add Files to ..." trong Xcode — nhớ tick Copy items if needed và chọn đúng target
Hình 4 · Sau khi add — file GoogleService-Info.plist nằm trong project navigator cùng cấp Info.plist
⚠ Multi-flavor: Đặt mỗi file GoogleService-Info.plist vào folder riêng (vd Config/Dev/, Config/Prod/). Dùng Run Script Phase trong Build Phases để copy đúng file theo Configuration (xem hướng dẫn nâng cao ở bước 7).

4 Thêm Firebase SDK qua CocoaPods

Mở Podfile và thêm:

Ruby · Podfile
target 'YourAppName' do
  use_frameworks!

  pod 'Firebase/Analytics'
  pod 'Firebase/Crashlytics'
end

Sau đó chạy:

Terminal
cd ios
pod install --repo-update
Dùng Swift Package Manager? Xcode → File → Add Packages → URL https://github.com/firebase/firebase-ios-sdk → chọn product FirebaseAnalytics + FirebaseCrashlytics.

5 Khởi tạo Firebase trong app

Sửa AppDelegate.swift (hoặc App.swift với SwiftUI):

Swift · AppDelegate.swift
import UIKit
import FirebaseCore

@main
class AppDelegate: UIResponder, UIApplicationDelegate {

  func application(_ application: UIApplication,
                   didFinishLaunchingWithOptions launchOptions: [UIApplication.LaunchOptionsKey: Any]?) -> Bool {
    // Firebase phải init NGAY sau khi app launch, trước mọi service khác
    FirebaseApp.configure()
    return true
  }
}

6 Bật forward UniTrack → Firebase

Sau khi Firebase chạy được, mở Portal → Project của bạn → tab Config (remote) → bật toggle "Firebase Analytics / Crashlytics" → Lưu.

SDK UniTrack ở app sẽ tự nhận cấu hình qua SSE và bắt đầu mirror mọi event tới Firebase trong vài giây.

7 (Nâng cao) Multi-flavor: copy plist đúng theo Configuration

Nếu app có nhiều Configuration (Debug-Dev / Debug-Prod / Release-Prod), thêm Run Script Phase trong Build Phases:

Bash · Run Script Phase
#!/bin/bash
# Chọn folder theo Configuration name
case "$CONFIGURATION" in
  *Dev*)     SRC="${SRCROOT}/Config/Dev/GoogleService-Info.plist" ;;
  *Staging*) SRC="${SRCROOT}/Config/Staging/GoogleService-Info.plist" ;;
  *)         SRC="${SRCROOT}/Config/Prod/GoogleService-Info.plist" ;;
esac

DEST="${BUILT_PRODUCTS_DIR}/${PRODUCT_NAME}.app/GoogleService-Info.plist"
cp -f "$SRC" "$DEST"
echo "✓ Copied $SRC → $DEST"

Drag Run Script Phase này lên trước "Copy Bundle Resources" — quan trọng để file có sẵn lúc build resource.

✓ Checklist hoàn thành

  • Tạo Firebase project trên Console
  • Đăng ký iOS app với đúng Bundle ID
  • Tải GoogleService-Info.plist và kéo vào Xcode target
  • Cài Firebase SDK qua CocoaPods/SPM
  • Gọi FirebaseApp.configure() trong AppDelegate
  • Build & chạy app lần đầu — Firebase Console sẽ báo "đã nhận data" sau ~5 phút
  • Bật toggle Firebase trên Portal → SDK UniTrack tự forward event
⚠ Lưu ý bảo mật GoogleService-Info.plist chứa API key public — KHÔNG có secret, an toàn để commit vào git. Nhưng vẫn nên giới hạn key trong Firebase Console (Authentication → Restrict to bundle ID).

🆘 Gặp lỗi?

  • "FirebaseApp.configure() was not called": thiếu gọi configure trong AppDelegate.
  • "No matching client found": Bundle ID trong Xcode ≠ Bundle ID lúc đăng ký Firebase app. Vào Firebase Console → Project Settings → Your apps → kiểm tra/edit.
  • Crashlytics không nhận crash: cần upload dSYM, chạy Build Phase script Firebase cung cấp hoặc upload thủ công.
  • App nhận 2 config: nếu có 2 file GoogleService-Info.plist trong bundle, kiểm tra lại copy script ở bước 7.
