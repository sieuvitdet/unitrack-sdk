📘 Setup Firebase 🐦 Flutter

🍎 iOS Native 🤖 Android Native 🐦 Flutter ⚛ React Native

Tích hợp Firebase vào dự án Flutter

Dùng FlutterFire CLI — tự động hoá cao nhất trong 4 platform. Chỉ ~3 phút cho 1 project, 5 phút cho multi-flavor.

⚙ Yêu cầu trước khi bắt đầu Flutter SDK ≥ 3.16 · Firebase CLI · FlutterFire CLI.

1 Cài Firebase CLI + FlutterFire CLI

Terminal
# Firebase CLI (Node.js, npm)
npm install -g firebase-tools

# FlutterFire CLI
dart pub global activate flutterfire_cli

# Login Firebase
firebase login

Nếu cmd flutterfire không nhận, thêm path vào shell:

Bash
export PATH="$PATH":"$HOME/.pub-cache/bin"

2 Tạo Firebase project (nếu chưa có)

Vào Firebase Console → tạo project. Không cần register app thủ công — FlutterFire CLI sẽ làm tự động ở bước 3.

3 Chạy flutterfire configure

Từ root project Flutter, chạy:

Terminal
cd path/to/your_flutter_project
flutterfire configure

CLI sẽ hỏi:

  • Chọn Firebase project (từ danh sách project bạn có)
  • Chọn platform: android, ios, hoặc cả 2 (dùng space để toggle, enter để confirm)
  • Cho phép tạo Firebase apps tự động (yes)

Sau khi xong, CLI sẽ:

  • Tạo file lib/firebase_options.dart — chứa config cho mọi platform
  • Tạo android/app/google-services.json
  • Tạo ios/Runner/GoogleService-Info.plist
  • Tự động sửa android/build.gradle và app/build.gradle
  • Tự động chạy pod install cho iOS

4 Cài Firebase packages

Terminal
flutter pub add firebase_core
flutter pub add firebase_analytics
flutter pub add firebase_crashlytics

5 Khởi tạo Firebase trong main.dart

Dart · main.dart
import 'package:flutter/material.dart';
import 'package:firebase_core/firebase_core.dart';
import 'package:firebase_crashlytics/firebase_crashlytics.dart';
import 'firebase_options.dart';

Future<void> main() async {
  WidgetsFlutterBinding.ensureInitialized();

  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );

  // Forward mọi error chưa catch → Crashlytics
  FlutterError.onError = FirebaseCrashlytics.instance.recordFlutterFatalError;

  runApp(const MyApp());
}

6 (Multi-flavor) Tạo config riêng cho mỗi env

Nếu app có dev/staging/prod, chạy flutterfire configure nhiều lần với option --out:

Terminal
# Dev
flutterfire configure \
  --project=myapp-dev \
  --out=lib/firebase_options_dev.dart \
  --android-package-name=asia.mobix.myapp.dev \
  --ios-bundle-id=asia.mobix.myapp.dev

# Prod
flutterfire configure \
  --project=myapp-prod \
  --out=lib/firebase_options_prod.dart \
  --android-package-name=asia.mobix.myapp \
  --ios-bundle-id=asia.mobix.myapp

Trong main.dart, switch theo flavor:

Dart · main.dart
import 'firebase_options_dev.dart' as dev;
import 'firebase_options_prod.dart' as prod;

const flavor = String.fromEnvironment('FLAVOR', defaultValue: 'dev');

await Firebase.initializeApp(
  options: flavor == 'prod'
      ? prod.DefaultFirebaseOptions.currentPlatform
      : dev.DefaultFirebaseOptions.currentPlatform,
);

Build với flavor:

Terminal
flutter run --dart-define=FLAVOR=prod

7 Bật forward UniTrack → Firebase

Mở Portal → Project → tab Config (remote) → bật toggle "Firebase Analytics / Crashlytics" → Lưu.

✓ Checklist hoàn thành

  • Cài Firebase CLI + FlutterFire CLI + login

  • Chạy flutterfire configure ở root project
  • Add packages: firebase_core + firebase_analytics + firebase_crashlytics
  • Gọi Firebase.initializeApp() trong main.dart

  • Build & chạy — Firebase Console nhận data sau ~5 phút
  • Bật toggle Firebase trên Portal

🆘 Gặp lỗi?

  • "command not found: flutterfire": thêm $HOME/.pub-cache/bin vào PATH.
  • "No Firebase App '[DEFAULT]' has been created": thiếu await Firebase.initializeApp() trước runApp().
  • iOS build fail sau khi configure: chạy cd ios && pod install --repo-update.
  • Android build fail "Could not find google-services.json": re-run flutterfire configure để regenerate file.
